# Sputnik-AI

Маленькая экспериментальная LLM, собранная из свежих блоков вместо стандартного трансформера:

- **линейное внимание** — каузальное ядро φ(x)=elu(x)+1, чанковый проход, O(T) по памяти вместо O(T²);
- **RWKV-блок** — channel-wise time-mixing с обучаемым затуханием, параллельный wkv через cumsum;
- **Mamba-блок** — selective SSM с чанковым сканом;
- **Micro-MoE** — вместо 8–16 больших «экспертов» сотни микро-блоков (+8 heavy с широким скрытым слоем);
- **адаптивный роутер** — сложность токена оценивается через энтропию гейта: на простых токенах активируется 1–2 эксперта из 128, на сложных — до k_max и heavy-эксперты;
- **морфологический токенизатор** — byte-level BPE поверх пред-разбивки русских слов на приставки/корни/суффиксы/окончания (`пере+ход+ы`). Маркеры: ▁ — начало слова, · — продолжение. Слияния не пересекают морфемные границы, поэтому русские слова не «съедаются» целиком.

## Размер по умолчанию

| параметр | значение |
|---|---|
| слои | 12, цикл lin → rwkv → mamba |
| dim / heads | 512 / 8 |
| FFN | каждый 3-й блок Micro-MoE (128 микро + 8 heavy), остальные dense MLP |
| vocab | 16384 |
| всего | ~75M параметров |

Tiny-конфиг (~19M): `SputnikConfig(dim=256, n_layer=8, n_expert=64, n_heavy=4, expert_hidden=48, seq_len=256)`.

## Старт

```bash
pip install -r requirements.txt

# 1. токенизатор
python scripts/train_tokenizer.py --input corpus.txt --vocab 16384

# 2. данные
python scripts/prepare_data.py --tokenizer tokenizer.json --input corpus.txt --out data

# 3. обучение
python train.py --data data --out out --steps 20000

# 4. генерация
python generate.py --ckpt out/sputnik.pt --tokenizer tokenizer.json --prompt "однажды утром"
```

Проверка численных блоков (чанковые сканы сверяются с эталонными последовательными):

```bash
python tests/test_scan.py
python demo.py
```

## Структура

```
sputnik/
  config.py          # конфиг модели
  tokenizer/
    morph.py         # морфологическая пред-разбивка
    bpe.py           # byte-level BPE
  model/
    attention.py     # линейное внимание (чанковое)
    rwkv.py          # RWKV time-mixing
    mamba.py         # selective SSM + чанковый скан
    router.py        # адаптивный роутер
    moe.py           # микро-эксперты
    block.py         # сборка блока
    model.py         # вся модель
train.py             # цикл обучения
generate.py          # сэмплирование (top-k / top-p)
scripts/             # токенизатор и подготовка данных
tests/               # сверка сканов с эталоном
```

## Замечания

- Текст нормализуется в нижний регистр, «ё» → «е».
- Инференс пока без кэша состояний (у RWKV/Mamba/линейного внимания состояние фиксированного размера — кэш в планах).
- Качество зависит от корпуса: нужен русский текст, хотя бы десятки МБ.

## Претрейн v1 (CPU, 2 ядра)

Конфиг: `dim=160, n_layer=4, n_expert=32, seq=256, batch=16` — 4.6M параметров.

| что | значение |
|---|---|
| корпус | 100M символов: русский веб (fineweb-2 ru), английский веб (c4), код (the-stack-v2 зеркало), русские код-инструкции |
| шаги / токены | 4000 / ~16.4M |
| lr | 1.2e-3, cosine, warmup 120 |
| loss | 9.76 → 4.43 (val) |
| скорость | ~1950 tok/s на CPU |
| чекпоинт | `out/sputnik.pt` (не в git, ~60MB) |

Токенизатор (vocab 16384), сжатие по доменам:

| домен | симв/токен |
|---|---|
| русский веб | 3.02 |
| английский веб | 3.95 |
| код | 3.68 |
| русские код-инструкции | 3.76 |

Для сравнения: byte-level BPE без морфологии даёт на русском ~1.7–1.9 симв/токен.

Адаптивность роутера (среднее число активных экспертов на токен по доменам):

| домен | k | loss |
|---|---|---|
| русский веб | 2.75 | 4.46 |
| код-инструкции | 2.81 | 1.37 |
| код (the-stack) | 2.86 | 4.44 |
| английский веб | 2.94 | 5.34 |

Проба: `python scripts/router_probe.py --inputs corpus/*.txt`.
