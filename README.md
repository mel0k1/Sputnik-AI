# Sputnik-AI

Маленькая экспериментальная LLM, собранная из свежих блоков вместо стандартного трансформера:

- **линейное внимание** — каузальное ядро φ(x)=elu(x)+1, чанковый проход, O(T) по памяти вместо O(T²);
- **RWKV-блок** — channel-wise time-mixing с обучаемым затуханием, параллельный wkv через cumsum;
- **Mamba-блок** — selective SSM с чанковым сканом;
- **Micro-MoE** — вместо 8–16 больших «экспертов» сотни микро-блоков (+8 heavy с широким скрытым слоем);
- **адаптивный роутер** — сложность токена оценивается через энтропию гейта: на простых токенах активируется 1–2 эксперта из 128, на сложных — до k_max и heavy-эксперты;
- **морфологический токенизатор** — byte-level BPE поверх пред-разбивки русских слов на приставки/корни/суффиксы/окончания (`пере+ход+ы`). Маркеры: ▁ — начало слова, · — продолжение. Слияния не пересекают морфемные границы, поэтому русские слова не «съедаются» целиком. Пробелы сверх первого идут отдельными претокенами — отступы в коде не схлопываются.

## Размер по умолчанию

| параметр | значение |
|---|---|
| слои | 12, цикл lin → rwkv → mamba |
| dim / heads | 512 / 8 |
| FFN | каждый 3-й блок Micro-MoE (128 микро + 8 heavy), остальные dense MLP |
| vocab | 16384 |
| всего | ~75M параметров |

Tiny-конфиг (~19M): `SputnikConfig(dim=256, n_layer=8, n_expert=64, n_heavy=4, expert_hidden=48, seq_len=256)`.

## Старт

```bash
pip install -r requirements.txt

# 1. токенизатор
python scripts/train_tokenizer.py --input corpus.txt --vocab 16384

# 2. данные
python scripts/prepare_data.py --tokenizer tokenizer.json --input corpus.txt --out data

# 3. обучение
python train.py --data data --out out --steps 20000

# 4. дообучение под чат-формат (50k пар из russian-code)
python scripts/prepare_sft.py --split
python train_sft.py --steps 3000 --bf16

# 5. генерация и болталка (пошаговый декод с кэшем состояний)
python generate.py --ckpt out/sft.pt --prompt "..."
python chat.py --ckpt out/sft.pt   # болталка: кэш состояний живёт между репликами
```

Проверка численных блоков (чанковые сканы сверяются с эталонными последовательными):

```bash
python tests/test_scan.py
python demo.py
```

## Структура

```
sputnik/
  config.py          # конфиг модели
  tokenizer/
    morph.py         # морфологическая пред-разбивка
    bpe.py           # byte-level BPE
  model/
    attention.py     # линейное внимание (чанковое)
    rwkv.py          # RWKV time-mixing
    mamba.py         # selective SSM + чанковый скан
    router.py        # адаптивный роутер
    moe.py           # микро-эксперты
    block.py         # сборка блока
    model.py         # вся модель
train.py             # цикл обучения (--bf16)
generate.py          # сэмплирование (top-k / top-p)
chat.py              # болталка: state cache между репликами
scripts/             # токенизатор и подготовка данных
tests/               # сверка сканов с эталоном
```

## Замечания

- Текст нормализуется в нижний регистр, «ё» → «е».
- Качество зависит от корпуса: нужен русский текст, хотя бы десятки МБ.

## Претрейн v2 (CPU, 2 ядра, bf16)

Конфиг: `dim=160, n_layer=4, n_expert=32, seq=256, batch=16` — 4.6M параметров.

| что | значение |
|---|---|
| корпус | 329M символов / 97.5M токенов: русский веб (fineweb-2 ru), английский веб (c4), код (the-stack-v2 зеркало, python), русские код-инструкции |
| шаги / токены | 4000 / ~16.4M |
| lr | 3e-4, cosine, warmup 200 |
| точность | bf16 autocast (AMX), веса fp32 |
| loss | 9.76 → 4.62 (val) |
| скорость | ~2200 tok/s (bf16), ~1950 у fp32 |
| чекпоинт | `out/sputnik.pt` (не в git, ~60MB) |

v1 отличалась корпусом и токенизатором без отступов: val 4.43.

Токенизатор (vocab 16384), сжатие по доменам:

| домен | симв/токен |
|---|---|
| русский веб | 3.02 |
| английский веб | 3.92 |
| русские код-инструкции | 3.66 |
| код (the-stack) | 3.12 |

Для сравнения: byte-level BPE без морфологии даёт на русском ~1.7–1.9 симв/токен.
Код подешевел с 3.68 до 3.12 симв/токен — плата за пробелы отступов отдельными токенами.

Адаптивность роутера (среднее число активных экспертов на токен по доменам):

| домен | k | loss |
|---|---|---|
| русский веб | 3.36 | 4.86 |
| код-инструкции | 3.38 | 2.64 |
| код (the-stack) | 3.49 | 5.00 |
| английский веб | 3.64 | 5.91 |

Проба: `python scripts/router_probe.py --inputs corpus/*.txt`.

## Кэш состояний

Все три блока внимания имеют состояние фиксированного размера (lin: S,z; rwkv:
prev,a,b; mamba: conv-буфер + h), поэтому генерация идёт по токену без
перепересчёна контекста: `model.step(idx, pos, states)`. Эквивалентность
полному проходу проверяется тестом: `python tests/test_step.py` (макс. расхождение
~3e-7). Скорость декода: ~190 ток/с на CPU против ~2 ток/с у полного форварда
на растущем контексте.

## Micro-MoE: gather-маппинг

Вместо цикла по 32 экспертам: пары (токен, эксперт) gather-ятся из селекта
роутера, сортируются по эксперту, паддятся до прямоугольника и считаются одним
`bmm` на слой (grouped GEMM), разброс — через `index_add_`. Цикл остался только
по двум группам весов (лёгкие/heavy — разная ширина) и как fallback при
экстремальном перекосе роутера. Эквивалентность старому циклу — бит-в-бит
(вперёд и градиенты), MoE ускорился в 1.6×: `python scripts/bench_moe.py --bench 8`.

## SFT v2 (russian-code, чат-формат)

База: претрейн-чекпоинт. Решения больше не выбрасываются по длине — режутся
по строкам под бюджет 255 токенов:

| режим | пар |
|---|---|
| v1 (дропали длинные) | 3 162 |
| v2: обрезка по строкам | 26 103 |
| v2: нарезка на несколько пар (`--split`) | 50 834 |

3 000 шагов, batch 8, lr 1e-4, bf16, маска лосса только на ответе;
loss ~2.7–3.4 (плавает по сложности пар). Модель держит формат датасета
и русский синтаксис («в этом примере функция принимает...», «вот пример того,
как...»); факты плавают — норма для 4.6M параметров.

Болталка: `python chat.py --ckpt out/sft.pt` — кэш состояний переиспользуется
между репликами, история не перекодируется (при переполнении окна кэш
перезаполняется с хвоста диалога).
